### [ToPath Saver — switch your download folder in two clicks](https://github.com/helpfulbriefl/topath-saver)

A small Chrome extension that decides **where the next download goes**: Documents, Images, Video, Archives or your own folder inside Downloads.

- Presets, a custom folder with live validation, and a one-shot "only for the next download" mode.
- Auto-sort by file type, keyboard shortcuts and a toolbar badge that shows the current folder.
- Light and dark themes; English / Russian / Chinese / Spanish interfaces.
- No analytics and no network requests — settings stay in the browser.
- TypeScript · React · WXT · Manifest V3 · Tailwind CSS · end-to-end tests with real downloads in Playwright.

[**Download the extension →**](https://github.com/helpfulbriefl/topath-saver/releases/latest) · [Source & install steps](https://github.com/helpfulbriefl/topath-saver)
